Story config (top level)

FieldTypeNotes
introSlideobjectOptional. See Intro slide.
slidesarrayRequired. See Slides.
tocOrientation"vertical" | "horizontal"Optional, default "vertical". Controls the table of contents layout.
themestring | objectOptional. Built-in theme name, or a custom theme object. See Theming. Custom theme objects and geoviewTheme not shown in demo config (the demo instead uses the data-theme HTML attribute).

Theming

Select a built-in theme by name:

{ "theme": "dark" }

Or fully customize (optionally based on a named theme via name):

{
  "theme": {
    "name": "dark",
    "mode": "dark",
    "primaryColor": "#ff6b35",
    "secondaryColor": "#00bcd4",
    "backgroundColor": "#121212",
    "paperColor": "#1e1e1e",
    "textColor": "#ffffff",
    "fontFamily": "'Georgia', serif",
    "geoviewTheme": "canada.ca"
  }
}
FieldTypeNotes
namestringBuilt-in theme to use as a base ("light" or "dark"); other fields here override it.
mode"light" | "dark"MUI light/dark mode.
primaryColor / secondaryColorstring (CSS color)Accent colors.
backgroundColor / paperColorstring (CSS color)Page background / card background.
textColorstring (CSS color)Primary text color.
fontFamilystringCSS font-family stack.
geoviewTheme"dark" | "light" | "geo.ca" | "canada.ca"Which GeoView map theme to sync to. GeoView only understands these 4 fixed names, so a custom app theme's look can't always be inferred automatically - set this explicitly if the auto-guess (based on mode) isn't what you want.

Reusing one config with a different theme

Rather than duplicating a config file just to get a themed variant of a page, add a data-theme attribute to the story container. It overrides whatever theme (if any) is set in the JSON: 

<div class="geoview-story" data-config="configs/my-story.json" data-theme="dark"></div>

See demo/index_dark.html, which reuses demo/configs/demo-story.json unmodified.

Intro slide

FieldTypeNotes
titlestringRequired.
subtitlestringOptional.
backgroundImagestringOptional.
logo{ src, altText }Optional.
scrimOpacitynumber (0-1)Optional, default 0.4. Darkening applied over backgroundImage so the title/subtitle stay readable (WCAG). Tune it down for images that are already dark, or up for busier/brighter ones. Not shown in demo.

Slides

FieldTypeNotes
titlestringRequired. Used for the slide heading, generated slide ID, and TOC entry.
backgroundImagestringOptional full-page crossfade background while this slide is active.
panelarrayRequired. One or more panels; see Panel types. A text panel paired with one media panel (image/video/map/slideshow) gets a side-by-side layout.
includeInTocbooleanOptional, default true. Set false to hide this slide from the table of contents.

Panel types

Every panel has an optional title in addition to its type-specific fields below.

text

FieldTypeNotes
contentstringRequired. Markdown.
cssClassesstringOptional extra CSS class(es) on the panel.

image

FieldTypeNotes
srcstringRequired.
altTextstringOptional.
captionstringOptional caption shown below the image.
fullscreenbooleanOptional, default true. Click (or Enter/Space) opens a full-screen view. Set to false, not shown in demo.

video

FieldTypeNotes
srcstringRequired.
videoType"local" | "external" | "YouTube"Required. "local"/"external" not shown in demo (only YouTube is).
captionstringOptional, used as the captions track source for local video.
transcriptstringOptional link to a transcript, shown below the video. Not shown in demo.
widthstring | numberOptional, local/external video width. Not shown in demo.
heightnumberOptional, iframe height for YouTube.
autoplaybooleanOptional, local/external video autoplay. Not shown in demo.

map

FieldTypeNotes
configstringRequired. Path to a GeoView map config JSON.
scrollguardbooleanOptional. Requires Ctrl/Cmd + scroll to zoom, so page scrolling isn't hijacked by the map.

quote

FieldTypeNotes
quotestringRequired.
authorstringOptional.
rolestringOptional.
organizationstringOptional.

slideshow

Image gallery carousel with dot navigation, back/forward arrows, and a full-screen viewer.

FieldTypeNotes
itemsarrayRequired. See below.
loopbooleanOptional, default false. Wrap around at the first/last image instead of disabling the arrow.
objectFit"cover" | "contain" | "fill" | "none" | "scale-down"Optional, default "cover". How each image fills the carousel frame. Only "contain" shown in demo.

items[]:

FieldTypeNotes
srcstringRequired.
altTextstringOptional.
textstringOptional overlay caption shown beside the image, on a semi-transparent backdrop.
textPosition"left" | "right"Optional, default "left". Which side the caption sits on - choose whichever side doesn't cover the important part of the photo.

interactive-map

FieldTypeNotes
configstringRequired. Path to a GeoView map config JSON.
pointsarrayRequired. See below.
durationnumberOptional, ms. Zoom animation duration for every point in this panel.
scrollguardbooleanOptional. Same as the map panel's.

points[] (points of interest):

FieldTypeNotes
titlestringOptional.
textstringOptional description shown on the POI card.
image / altTextstringOptional photo shown at the top of the card.
fieldstringOptional feature attribute name to read and display live from the map service. Not shown in demo (the demo uses target.value instead, a static author-provided label).
target.layerIdstringLayer path, e.g. "geoviewLayerId/layerId".
target.oidstring | numberFeature object ID to zoom to.
target.valuestring | numberOptional static label for the POI (shown if field isn't set or the live value is unavailable).
target.scalenumberTarget map scale denominator (e.g. 50000 for 1:50,000) to zoom to.
target.zoomnumberExplicit target zoom level; takes precedence over scale if both are set. Not shown in demo (the demo only uses scale).
target.returnHomebooleanIf true, this POI returns the map to its initial extent instead of zooming to a feature.

dynamic (reserved)

This panel type is defined in the schema (content, contentWidth, reversed, children) but is not implemented yet - it's a placeholder for a future composable panel type. Avoid using it in configs for now.
