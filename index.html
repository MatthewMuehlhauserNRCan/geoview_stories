GeoView Story Library

A React-based storytelling library for creating interactive stories with GeoView maps.

📦 CDN Link

https://matthewmuehlhausernrcan.github.io/geoview_stories/geoview-story.js

Option 1: Auto-Init with Data Attributes (Recommended)

<!-- Include GeoView -->
<script src="https://canadian-geospatial-platform.github.io/geoview/public/cgpv-main.js"></script>

<!-- Include GeoView Story library -->
<script src="https://matthewmuehlhausernrcan.github.io/geoview_stories/geoview-story.js"></script>

<!-- Add a container with class and data-config -->
<div 
  class="geoview-story" 
  data-config="path/to/your-story.json"
></div>

Option 2: Manual Init with JavaScript

<!-- Include libraries -->
<script src="https://canadian-geospatial-platform.github.io/geoview/public/cgpv-main.js"></script>
<script src="https://matthewmuehlhausernrcan.github.io/geoview_stories/geoview-story.js"></script>

<!-- Add a container -->
<div id="my-story-container"></div>

<!-- Initialize manually -->
<script>
  window.geoviewStory.init('my-story-container', 'path/to/your-story.json');
</script>
